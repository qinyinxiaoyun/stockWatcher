# 阶段 3：后续首次服务器部署边界

当前阶段 0～2 只完成本地开发和验证。没有连接真实服务器、配置公网DNS或启用生产监控；本文件不是已经验通的服务器安装手册。

后续阶段开始时先只读检查服务器 OS、CPU 架构、内存、磁盘、Docker/Compose、端口和现有代理，确认采用对应发行版的官方安装步骤。不要默认安装宝塔或覆盖现有 Nginx/Caddy 站点。

约定固定项目名 `stock-watch`，环境文件 `/srv/stock-watch/shared/.env`，持久数据 `/srv/stock-watch/shared/data/`，目录可写 UID/GID 10001；发布目录与共享配置/数据分离。Compose 的插值环境文件和容器 env_file 都需显式指向同一共享文件。首次 `MONITOR_ENABLED=false`，app/worker 使用同一镜像，Caddy固定证书卷。

阶段3须补齐并真实验证：可重复的首次部署入口、发行包、HTTPS/回调/指定成员测试消息、资源峰值与重启恢复、旧系统停用和最终seen导入。阶段4再实现服务器bare Git、部署队列、状态查询和回滚演练。当前本地Git已提前初始化，符合本轮最新要求；不再等服务器部署阶段才建立本地历史。
