# 本地运行及数据约定

## 配置

SQLite 中 `config_state` 维护递增配置版本，stocks/themes 使用稳定 ID，审计保存操作者、来源消息 ID 与前后版本。股票带市场代码；新增与恢复记录生效时间，关注点调整不重置 seen。名称只能匹配已配置目标或服务端明确维护的候选，模型生成的证券代码不能充当可信来源。

一次新闻轮次读取一次配置快照，检索和分析使用同一版本。主题有独立关键词与检索任务；关注点用于分析重点，不是强制排除其他重大新闻的筛选器。空名单合法，初始化不能复活用户删除的默认目标。

## 消息、任务和回执

回调先验签、解密并验证企业/应用及管理员身份。无 MsgId 的事件使用稳定散列去重。明确指令在短事务内处理；配置、审计、inbox 完成状态和 outbox 回执一起提交。回执收件人固定为发起人，不使用预警广播收件人。

自然语言保存读取时的快照和配置版本后交给 worker。模型调用期间不持有写事务，结构/字段/目标验证全部通过才原子应用；版本冲突要求用户重新检查。失败只产生回执，不修改配置。任务有租约，进程中断后可重新领取；配置应用和任务完成同事务，避免重复修改。

## 新闻与投递

首次原始目标建立基线，24 小时已有新闻不推送。新增/恢复目标从生效时间起纳入监控。每轮最多分析 10 条，忽略超过24小时或未来超过1小时的新闻；seen 保留15天。新闻合并多目标匹配，提示词包含真实配置及关注点。

新闻分析、seen 和必要的 outbox 在同一短事务提交。分析失败不标记 seen；投递失败依靠持久 outbox 重试。已被企业微信接受的分段逐段记录，重试从剩余分段开始；响应丢失或接受后落库前崩溃时可能重复，不能保证端到端严格一次。指数退避后进入 dead 的消息可经 `retry-outbox ID` 手动恢复。

调度固定北京时间工作日 09:00 至15:00每5分钟一次，不排除法定休市日。计划时间槽和全局监控租约防重；不补跑离线所有历史时间槽。`MONITOR_ENABLED` 只控制自动新闻调度，管理指令与回执仍可工作。不要在 Web worker 中启动调度器或额外设置宿主机 cron。

## SQLite 与备份

默认使用 rollback journal（DELETE）及短事务、busy timeout。开发环境 SQLite 为3.50.4；官方确认该版本仍受 WAL-reset bug影响，因此默认不启用WAL。未来启用WAL前必须核对实际容器SQLite包含修复（官方列出3.51.3及以后，或3.50.7/3.44.6回补版本），不能仅看Python版本。

`backup` 使用 SQLite online backup API 并做 integrity_check，目标必须不存在。恢复演练在独立路径执行；真实恢复需先停写，明确备份时点之后配置/任务丢失范围，不能随着代码回滚覆盖共享数据库。运行数据、环境文件与证书均不属于代码发布物。

## 组织内独立订阅（schema3）

旧全局模式保留兼容；成员准入不会自动启用独立订阅。显式指定唯一旧配置拥有者后，迁移完整配置、审计及已处理基线，再设置持久模式标志。迁移事务拒绝未完成旧通知/意图任务和仍存活的监控租约；schema3升级不能以旧schema2应用直接回退。常驻worker每轮重读模式，旧流程认领租约时也检查模式，防止切换竞态产生广播。

成员按已核验组织ID/UserID准入；普通成员和管理员在微信中都只操作本人订阅，成员准入/撤权使用可信本地运维入口。成员配置以完整领域行JSON持久化，在隔离内存SQLite中复用原ConfigStore校验及命令规则，再用成员版本和资格代次在共享库短事务保存；没有每成员数据库文件或独立调度器。新成员为空订阅，撤权后恢复只重新启用既有启用目标的生效时间，不补发停用期间旧闻。

回调、确认、上下文、审计、异步任务及回执均绑定成员。自然语言任务冻结本人的快照，模型调用前后均重新检查成员代次及配置版本；模型不得选择成员或收件人。队列有组织总量和每成员限额，已撤权任务不应用旧修改。

检索需求共享采集，文章版本持久化。AI按文章内容、目标及规范化关注需求划组，同文不同目标分别判断；公开需求在组织内复用，设置私有分析后使用成员独立缓存域。模型、提示词及输出结构版本参与缓存；收件人、阈值等通知设置不使分析缓存全量失效。关注点不排除目标的其他重大风险，推送按成员当前规则判断。

成员评估与全局文章池分开，同一成员同篇多项命中合并一条定向通知并分别展示各目标影响；评估与通知入队同事务。发送每段前检查成员和订阅资格，成员通知不回退到全局收件人，保留已有分段检查点与未知网络结果可能重复的限制。显式历史补查必须指定成员和唯一目标；首次生效、暂停/恢复、旧基线和正常配置变更保持不自动重发旧闻。

具体实施与后续来源/日报安排见[INDEPENDENT_SUBSCRIPTIONS.md](INDEPENDENT_SUBSCRIPTIONS.md)。
