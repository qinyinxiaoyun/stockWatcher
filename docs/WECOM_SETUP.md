1. 管理员登录 <https://work.weixin.qq.com/wework_admin/frame>；如果还没有可管理的企业/组织，先按平台引导创建组织。

3. 创建后记录AgentId；Secret旁点击查看，按提示使用管理员企业微信移动端确认。进入“我的企业”查看企业ID。界面参考[腾讯官方图文说明](https://cloud.tencent.com/document/product/1831/138263)。
4. 在通讯录找到测试成员的账号UserID，明确是否同一成员同时作为命令管理员与预警收件人；不要用手机号或显示姓名代替UserID。
5. 本机已准备被Git忽略且只允许当前用户读取的 `.env.production.local`。将企业ID、AgentId、Secret、成员账号和已有DeepSeek API Key填入对应空项，保存即可，不粘贴到聊天。回调Token和EncodingAESKey已由助手生成，暂不修改。

本文件不会自动上传或启用监控。服务器先加载相同回调参数，再保存企业微信后台回调；本项目回调URL为 `https://stock.janettepa.uk/wecom/callback`。当前后台要求先设置可信域名或接收消息服务器URL后才能配置可信IP，因此先完成“设置API接收”并保存成功，再添加 `66.135.8.221`。

EncodingAESKey必须是43位ASCII字母数字。本项目首次生成值含Base64符号，与后台UI不兼容，已重新生成并同步；操作者需重新打开私密文件，只复制等号右侧的新值，不带字段名、等号、引号或空格。生成时使用随机32字节编码后的完整Base64串，仅接受全部字符为字母数字的候选，并检查严格解码及重新编码一致，不能直接删除符号凑长度。底层协议解密仍保留标准Base64兼容性。企业可信IP/域名校验按实际后台要求处理，助手可上传服务器验证文件。创建应用不需要购买新服务器或重复创建DeepSeek密钥。
